# SauceDemo Manual Testing Project

## Project Overview
This project documents manual testing of the SauceDemo
e-commerce demo application.

Application URL: https://www.saucedemo.com/

## Objectives
- Perform manual testing of e-commerce functionality.
- Design and execute test cases.
- Record actual and expected results.
- Capture screenshots as testing evidence.
- Document defects found during testing.

## Testing Scope
- Products page verification
- Product name verification
- Product price verification
- Add to Cart functionality
- Product sorting
- Checkout functionality
- Login validation

## Tools Used
- SauceDemo
- LibreOffice Calc
- Visual Studio Code
- Git
- GitHub

## Project Structure
- Manual-Testing: Test cases and bug reports
- Screenshots: Testing evidence
- Reports: Test summary reports
